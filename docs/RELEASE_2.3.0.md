# Tribal Power 2.3.0 — The living camp

- Illustrated standalone Spirit Codex with 63 teachings, 13 creature portraits, animated examples, search, bookmarks, live crafting and processing recipes, and an explicit spoiler warning.
- Wayanchor chunk loading, Hush Totem hostile-spawn wards, Grove Tender farming, and ritual-driven Summoning Cradles.
- Binding Effigies harmlessly imprint 21 supported species. A three-voice ritual grants 512 successful summons; exhausted bindings require renewal. Failed summons consume no resources, and saved/picked-up effigies keep their use count.
- Spirit Lanterns, weather-reading Rain Chimes and 27-slot Offering Tables bring functional decoration to the camp.
- Redstone pauses all camp devices; standard item capabilities support hoppers, pipes and relays.
- Standalone recipes and nine new Codex teachings. Ninjacat Skies 0.6.0 adds ten connected quests, including binding and summoning milestones.

Validation: Java 21 / Minecraft 1.21.1 / NeoForge 21.1.249; production build and all 38 server GameTests passed. Standalone client opened the native book, rendered the new models in the recipe view and read live recipes from the server. Full campaign playthrough remains ongoing.
