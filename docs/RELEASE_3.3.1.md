# Tribal Power 3.3.1

- Player machines drop themselves when broken, even by hand. They no longer require a tagged pickaxe that most of them were missing from.
- Inventories dump on break: Echo stations, Song Bench, caches, Listening Pit, Stone Font, Pulse Resonator catalyst, Ember Horn fuel, camp devices, ritual seals.
- World stone (March stone / cobble / ore) still needs a pickaxe.
