# Spirit Codex artwork

The open-book frame in `textures/gui/codex/book.png` was generated with OpenAI image generation on 2026-09-07. Brief: ornate empty dark-navy grimoire pages, bronze and gold borders, turquoise gems, left navigation area and a vertical spine; no lettering. The native UI adds all live text, buttons, item models and animation. The 1568-by-1003 source is sliced into the responsive book layout.

Creature illustrations reuse the project's existing Blender-derived portraits. Camp objects use original native Minecraft cuboid models generated by `tools/generate_camp.py` and the existing Tribal Power material textures, including animated loom light.
