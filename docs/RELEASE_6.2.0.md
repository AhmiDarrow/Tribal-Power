# Tribal Power 6.2.0 - In Your Language

Now available in Spanish, French, German, Portuguese (Brazil), Italian, Russian, Polish, Japanese, Korean and Chinese (Simplified). Follows your Minecraft language setting.

- **The mod follows Minecraft's language.** Esc, Options, Language. Names, tooltips, the Spirit Codex, advancements, elder dialogue, config labels and song titles switch with it. English remains the fallback when a line has no translation.
- **Spanish covers Spain and Latin America.** The Mexican Spanish file matches the Spanish one.

Minecraft 1.21.1, NeoForge 21.1.249.

GitHub: https://github.com/AhmiDarrow/Tribal-Power/releases/tag/v6.2.0
