# Tribal Power 5.3.7 - Every drum sounds

The Songkeeper Drum plays every song it lists, and every pad answers.

- **The Ninjacat guardian themes play.** With Ninjacat Skies Core 0.5.16 or later, all twelve guardian themes sound on the drum. Core 0.5.15's recordings could not be played by the game, so the drum now lists those songs only with a Core that carries playable ones; the Chocobos Reborn races and Tribal Power's own songs are unchanged.
- **A, S, D and F always drum.** A rebound or stray key setting could leave a lane dead (one pad never fired). The drum now takes your own lane keys, plus A S D F and the arrow keys, whatever else they are bound to.

Minecraft 1.21.1, NeoForge 21.1.249.
