# Tribal Power 5.6.1 - Separate Destinations

Ranked item and fluid relay plates can send each channel to a different place.

- **Plain tuner clicks fill the next free channel.** Mark a face with the Lattice Tuner, then use it on the plate. The first click aims channel 1, the next aims the next channel that has no destination, and so on.
- **Sneak-click replaces the selected channel.** Pick that tab, then sneak-use the tuner on the plate. Unlink still forgets only that channel's destination and keeps its filter.
- **The plate shows where each channel goes.** The filter line and the tab tooltip name that channel's coordinates and face.
- **One transfer a beat, as before.** An empty filter still sends to the first channel with room. Give later channels a filter, or switch to round-robin, when they should receive goods before the first one overflows.

Minecraft 1.21.1, NeoForge 21.1.249.
