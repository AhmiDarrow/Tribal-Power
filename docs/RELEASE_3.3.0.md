# Tribal Power 3.3.0

- Pulse machines cost more (`consumptionMultiplier` default 2.0). A hand Drumheart still runs Stone Font cobble. Echo stations, the Listening Pit, and the Ember Kiln do not.
- Echo Shatter hammers cobble → gravel → sand → Ex Deorum dust (clay if Ex Deorum is absent). Echo Shards come from stone, deepslate, and March stone — not cobble.
- Ember Kiln: Fire-attuned station that smelts (including grit) for Pulse.
- Mineral grit tints are stronger, with named colours for common pack metals.
- Dock stalls: Kin NBT `Stall=1` + datapack `data/*/tribalpower/dock_shop`. No standing gate.

Minecraft 1.21.1, NeoForge 21.1.249.
